# ClickIt — Product Guide

## Vision
ClickIt is a native macOS auto-clicker built for precision and power users.
It delivers sub-10ms click timing accuracy — the best available on macOS —
for users who demand reliable, professional-grade automation.

## Goals
1. Deliver the most precise click timing available on macOS
2. Provide advanced automation control for power users

## Target Users

### Gamers
Automate repetitive in-game clicking (idle games, MMO grinding,
achievement farming) without sacrificing timing accuracy.

### Productivity & Business Users
Automate repetitive workflows — data entry, batch processing,
monitoring tasks — with reliable, configurable click sequences.

## Distribution
Open-source releases via GitHub only. No Mac App Store.

## Differentiators
- Sub-10ms timing accuracy — industry-leading precision on macOS

## Current Phase
**Stabilization** — Feature set is largely complete. Focus is on
bug fixes, UX polish, and code quality. Intel (x86_64) support
is being discontinued; development targets Apple Silicon only.

## Architecture Note
ClickIt ships two variants:
- **ClickIt Pro** — Full-featured version
- **ClickIt Lite** — Simplified, lightweight version
